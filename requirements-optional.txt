# Face recognition works WITHOUT anything in this file: `requirements.txt`
# installs opencv-contrib-python-headless, and the YuNet + SFace ONNX models are
# downloaded on first use. This file is only for the dlib-based backend, which
# is more accurate but needs a compiler.
#
# Choose a backend with `backend=` on FacialRecognitionPipeline, or let it
# auto-detect (it prefers dlib when importable, so existing encodings keep
# working).
#
# On PythonAnywhere: skip this file entirely. dlib needs cmake and Boost, which
# shared hosting does not provide.
#
#   Ubuntu/Debian prerequisites:
#       sudo apt-get install -y cmake build-essential libboost-all-dev \
#           libopenblas-dev liblapack-dev libx11-dev libgtk-3-dev espeak1
#
#   pip install -r requirements-optional.txt
# =============================================================================
